# 六福珠寶智能營運工具

## 第一版功能

- PWA 首頁，可加入手機主畫面
- 智能報價頁
- 手機相機掃描 QR Code
- 上傳 QR Code 圖片
- 手動貼上 QR 文字
- 自動填入貨號、模號、金重、款式碼、供應商代碼、編入日期及工費／標價
- 同步 Cloudflare Worker 今日飾金售出價
- 顯示原價、半工、免工、全單 95 折、金價 95 折半工及金價 95 折免工
- 一鍵複製報價摘要

## QR 格式

`貨號/模號/金重/款式碼/供應商代碼/編入日期/工費或標價/其他欄位`

範例：

`ELEG8040F9A/D3428/78.78/H2294/G8160/25-06-30/10129//0`

## 使用方法

1. 開啟 `smart-quote.html`。
2. 選擇「開啟相機掃描」或上傳 QR Code 圖片。
3. 核對自動填入的貨品資料。
4. 等候今日金價同步，或手動輸入售出價。
5. 查看報價結果並複製摘要。

## 注意

- 相機功能需要 HTTPS。
- QR 掃描使用 `html5-qrcode` CDN；首次使用需要網絡。
- 工費與標價目前共用同一欄位，實際定義應按公司已確認口徑使用。
- 報價結果只供參考。
