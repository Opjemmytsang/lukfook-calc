LUKFOOK SMART OPS

六福珠寶智能營運工具

集中使用智能報價、QR 貨品資料讀取、貴金屬計算、飾金折扣情景及利潤推算。可在手機瀏覽器加入主畫面，以接近 App 的方式使用。
PWA 網頁 App手機／iPad／電腦營運工具統一入口
TOOL 01 NEW
智能報價
掃描貨品 QR Code，自動拆分貨品資料並填入報價欄位，再同步今日飾金售出價。
  • 讀取貨號、模號、金重及款式碼
  • 讀取供應商代碼、編入日期及工費／標價
  • 即時比較原價、半工、免工及 95 折方案
開始智能報價
TOOL 02
貴金屬回收／兌換／賣出
原有日常營運主工具，支援賣出、買入、兌換及不同展示模式。
  • 飾金／添富金／金粒金條／鉑金
  • 內部版面及對客展示版面
  • 原有功能完整保留
進入主版系統
TOOL 03
飾金折扣情景計算器
手動輸入金重及工費，集中檢視不同折扣方案下的金額結果。
  • 同步今日飾金售出價
  • 集中比較多個折扣情景
  • 一鍵複製摘要
進入情景分析
TOOL 04
利潤推算器 v1
輸入金重、金價、單據金額、工費及成本，推算毛利、毛利率及佣金。
  • 支援両／克換算
  • 估算免工後利潤影響
  • 摘要複製及風險提示
進入利潤推算器
安裝方法：iPhone 使用 Safari 開啟後按「分享」→「加入主畫面」；Android 使用 Chrome 選單內的「安裝應用程式」。以上資料只供參考。
