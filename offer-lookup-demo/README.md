# 分行優惠貨號查詢｜企業微信整合原型

> **安全邊界：本分支只包含前端原型和虛構 DEMO 貨號。沒有真實公司貨號、優惠名單、價格、員工資料或登入密鑰。**

## 使用

開啟 `index.html` 可查看「分行手機查詢」及「營運部管理後台」兩個介面。測試虛構貨號：
- `DEMO-J-001`：港澳尊享價＋激賞價
- `DEMO-J-002`：港澳35周年優惠
- `DEMO-OS-001`：海外尊享價
- `DEMO-OS-002`：海外35周年優惠

管理頁可新增／刪除虛構貨號、暫存、撤銷、手動發布。只使用瀏覽器本地儲存模擬狀態；**沒有真正企業微信身份驗證、共用資料庫或安全管理權限**。

## 正式部署必須由公司 IT 建立

1. 公司控制的 HTTPS 安全查詢入口；不能將真實優惠名單部署到 GitHub Pages。
2. 企業微信網頁 OAuth 及企業 ID、員工有效狀態、部門／分行授權檢查（伺服器端）。
3. 五份正式 Excel 匯入公司內部資料庫；員工查詢 API **只回傳單一貨號的結果**，避免清單下載、枚舉，並施行速率限制、日誌及審計。
4. 管理後台分權：上傳／比對差異 → 待審批 → 營運部手動確認 → 發布正式版本 → 保留歷史及回滾。
5. 安全審查：TLS、CSRF、cookie、資料最小化、登入閒置逾時、備份、訪問日誌、漏洞測試。
6. 最終由 IT 決定是否在企業微信工作台提供入口；群組分享連結亦可，但**連結本身不能視作身份驗證**。

## 技術限制

企業微信員工身份驗證需要管理員協助配置；不能純靠瀏覽器辨識是否來自本公司企業微信。分行手機若只能用一般互聯網，就需要 IT 批准的對外安全查詢閘道；不能直接讀取公司內網資料。

**禁止將原始 Excel、seed.json（真實版）、資料庫檔、API 密鑰或憑證提交至本儲存庫。**
