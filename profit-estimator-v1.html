利潤推算器 v1

用於快速推算單件貨品的基礎收入、佣金收入、實收總額、成本基準及最終利潤。現版本已加入兩套邏輯：A1 會改用市價模式倒推出毛利；G 類 / 計重黃金 則保留以金重及金價計算成本。

現行計算邏輯：
  • A1：成本基準 = 市價成本基準；最終利潤 = 實收總額 −（市價成本基準 + 石 / 配件成本 + 其他成本）
  • G 類：成本基準 = 金重（両）× 當日金價（每両）；最終利潤 = 實收總額 −（金料成本 + 石 / 配件成本 + 其他成本）
  • 佣金收入 = 基礎收入 × 佣金比率，並加到實收總額之內。
